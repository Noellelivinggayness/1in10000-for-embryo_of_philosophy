# one in 10000 chances every seconds to spawn embryo_of_philosophy
Minecraft add-on mod for Star Rail: Apocalyptic Shadow

Adds a random chance to spawn embryo_of_philosophy in the world

the config has options for:
- disabling default integration (embryo_of_philosophy)
- enabling optional integration (not yet available in Star Rail: Apocalyptic Shadow)
- Debug (DO NOT USE ON SERVERS)

the following commands are added when cheats and/or "Debug" are/is enabled:
- testtestthing: use by itself summons embryo_of_philosophy in a specific way
- killtest: use by itself kills embryo_of_philosophy (does not work on the real one)

Report issues on Github

Known issues:
- sometimes the insta-death attack kills you in creative most often it does not (can't/won't fix)
- sometimes embryo_of_philosophy won't kill you this is mostly due to the original mod but I could fix it by using another approach as I'm currently using /kill on behalf of the player to trigger embryo_of_philosophy (might fix if I get a reply from the original author)

# Build instructions
require a java jdk between 8 and 22
```
git clone https://github.com/Noellelivinggayness/1in10000-for-embryo_of_philosophy.git
cd 1in10000-for-embryo_of_philosophy
./gradlew build
```
